## About

**GitReplay** is a free browser app for exploring GitHub repositories. Connect your GitHub account, pick one of your repos or paste any repo link you can access, browse the file tree, and replay files as they type out on screen. Web projects also show a **live preview** as HTML, CSS, and JavaScript are built.

Nothing to install. Open the link and start. Your session stays in this browser tab and clears when you close it.

## Features

- **Connect with GitHub** — sign in with your account (no token pasting)
- Browse repositories you can access, including private ones
- Character-by-character file replay with pause, speed, and scrub controls
- Live preview for websites, markdown, images, and media
- Replay All, plus HTML / JS / CSS race modes
- Runs entirely in the browser on GitHub Pages

---

## Quick start

1. Open [GitReplay](https://delexoo.github.io/GitReplay/)
2. Click **Connect with GitHub** and authorize the app
3. Choose a repository from your list, or paste a URL such as `github.com/vitejs/vite`
4. Single-click a file to read it · Double-click to replay it live
